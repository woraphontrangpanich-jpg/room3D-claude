# Kenney Furniture Kit - GLB Ready Pack

This package is a GLB-focused redistribution of the CC0 Furniture Kit by Kenney.

It is intended for quick import into 3D tools, game engines, illustration workflows, and general scene dressing.

## Included

- `models_glb/` - 140 GLB furniture models
- `renders_isometric/` - isometric PNG reference renders from the source package
- `renders_side/` - side-view PNG reference renders from the source package
- `MODEL_LIST.txt` - file list for the GLB models
- `License_Kenney.txt` - original license text included with the source package
